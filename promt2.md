Saya ingin mengubah dan mengembangkan bagian Menu pada website **Mahligai Bakery** agar menjadi katalog bakery yang lengkap, modern, profesional, elegan, menarik, responsive, dan mudah digunakan. Website menggunakan Laravel dan struktur project yang sudah ada harus tetap dipertahankan. Sebelum melakukan perubahan, periksa terlebih dahulu struktur project, komponen Menu, file CSS, JavaScript, database, dan komponen lain yang sudah tersedia agar tidak membuat file atau komponen duplikat serta tidak menghapus fitur yang masih digunakan. Fokus perubahan utama adalah bagian Menu dan katalog produk.

Gunakan tema desain Mahligai Bakery yang sudah ada dengan kombinasi warna **hijau muda dan hijau tua**, kemudian gunakan putih dan cream sebagai warna pendukung. Buat setiap kategori produk mempunyai tampilan yang menarik dan tidak monoton. Gunakan card modern, rounded corner, shadow lembut, border yang halus, typography yang elegan, badge, hover effect, animasi yang smooth, spacing yang rapi, dan responsive design untuk desktop, laptop, tablet, serta smartphone.

Menu Mahligai Bakery harus memiliki tiga kelompok utama yaitu **ROTI UNYIL ANEKA RASA**, **ROTI SISIR**, dan **ANEKA ROTI (REGULAR BREAD)** serta kategori Aneka Roti tambahan seperti Roti Tawar, Roti Sisir Plain, Roti Gandum, Roti Multigrain, Roti Sobek Cokelat, dan Roti Sobek Pandan.

Jangan membuat foto random, jangan mengambil foto dari internet, dan jangan membuat gambar AI untuk produk ini. Gunakan desain berbasis typography, icon bakery, badge, card, dan elemen dekoratif agar tetap terlihat profesional walaupun tidak menggunakan gambar.

Untuk semua produk yang nantinya memiliki foto, **saya sendiri yang akan memasukkan dan mengganti foto produknya**. Jangan membuat gambar produk secara otomatis, jangan mencari gambar dari internet, dan jangan mengganti gambar dengan foto random. Siapkan struktur gambar menggunakan field atau placeholder seperti `image`, `gallery`, `avatar`, atau struktur gambar yang sudah tersedia di project. Saya nantinya hanya perlu mengganti file atau path gambar tanpa harus mengubah struktur komponen.

Jika suatu produk belum memiliki gambar, gunakan placeholder sederhana atau desain tanpa gambar. Untuk Roti Unyil, jangan memaksakan penggunaan foto karena memang tidak ada gambar.

Buat setiap produk dapat dibuka untuk melihat detail. Detail dapat menggunakan modal, expandable card, drawer, atau detail panel. Detail harus menampilkan nama produk, deskripsi, varian, harga, paket, Additional, dan gambar jika tersedia.

Gunakan struktur data produk yang mudah dikembangkan dan diubah. Nama produk, varian, harga, gambar, deskripsi, paket, dan Additional sebaiknya tidak ditulis secara berantakan di banyak tempat sehingga nantinya mudah diperbarui.

Buat navigasi Menu yang mudah digunakan. Pengguna dapat memilih kategori seperti:

- Roti Unyil
- Roti Sisir
- Aneka Roti
- Roti Tawar

Tambahkan smooth scrolling atau filtering jika sesuai dengan struktur website yang sudah ada.

Gunakan animasi yang halus dan profesional seperti fade-in, slide-up, hover effect, card lift, image zoom untuk gambar yang tersedia, modal animation, carousel transition, dan smooth transition. Jangan menggunakan animasi secara berlebihan.

Pastikan semua tampilan responsive pada desktop, laptop, tablet, dan smartphone. Card produk, daftar varian, harga, paket, Additional, modal, dan gallery harus tetap mudah dibaca pada layar kecil.

Pertahankan fitur website lain yang sudah ada seperti Navbar, Hero Section, Tentang Mahligai Bakery, Lokasi, Jam Operasional, Kontak, Gallery, Testimoni, AI Assistant, Footer, dan fitur lainnya. Jangan menghapus atau merusak fitur yang tidak berhubungan dengan perubahan Menu.

Website menggunakan Laravel. Jika membutuhkan database untuk menyimpan produk, kategori, harga, gallery, atau data lainnya, gunakan Laravel Migration, Model, Controller, Seeder, dan struktur Laravel yang sesuai. Jangan membuat tabel database secara manual melalui phpMyAdmin.

Gunakan Tailwind CSS untuk styling utama, CSS custom untuk kebutuhan styling atau animasi khusus, dan JavaScript terpisah untuk interaksi seperti filtering, modal, carousel, gallery, navbar, dan fitur interaktif lainnya. Jangan mencampurkan seluruh CSS dan JavaScript ke dalam satu file.

Untuk AI Assistant Mahligai Bakery yang sudah ada atau akan dibuat, gunakan API Gemini melalui backend Laravel. API Key tidak boleh ditulis langsung di JavaScript frontend, HTML, atau file public. Simpan API Key menggunakan environment variable di `.env`, misalnya `GEMINI_API_KEY=`, dan gunakan backend Laravel untuk melakukan request ke Gemini. Jangan pernah menampilkan API Key kepada pengguna atau memasukkannya ke source code frontend.

Sebelum melakukan implementasi, periksa terlebih dahulu kode yang sudah ada dan tentukan file mana yang perlu diubah. Gunakan kembali komponen yang sudah tersedia jika memungkinkan. Jangan membuat file duplikat. Jangan menghapus kode yang masih digunakan. Jangan mengubah fitur lain yang tidak diperlukan.

Jangan mengarang nama produk, varian, harga, jumlah pcs, jumlah slices, kemasan, atau biaya Additional. Gunakan data yang diberikan dalam prompt ini sebagai sumber utama. Jika terdapat informasi yang belum diberikan, gunakan placeholder yang mudah diganti.

Tujuan akhirnya adalah membuat bagian Menu Mahligai Bakery menjadi katalog bakery profesional dan interaktif yang memiliki **Roti Unyil Aneka Rasa, Roti Sisir, Aneka Roti (Regular Bread), dan Aneka Roti lainnya**, lengkap dengan varian, paket, harga, Additional, detail produk, struktur gambar yang dapat saya ganti sendiri, serta tampilan modern yang sesuai dengan identitas Mahligai Bakery. Jangan hanya membuat tampilan sederhana; buat hasil akhirnya terlihat seperti website bakery profesional yang siap dikembangkan lebih lanjut.
